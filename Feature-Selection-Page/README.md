📁 Feature Selection Project

📌 Description
This project is a feature selection UI component built using HTML and CSS. It was created as part of FreeCodeCamp exercises to practice custom form controls and advanced CSS pseudo-class styling.

✨ Features
Feature cards using <label> elements
Custom styled checkboxes
Checkmark indicator (✓) when selected
Interactive checked states
Clean card-based layout
Hover and selection effects

🛠️ Technologies Used
HTML5
CSS3

🎯 Key Concepts Practiced
Custom checkbox styling using appearance: none
:checked pseudo-class
::before pseudo-element for checkmark
CSS borders and box styling
Label-input relationship
Flexbox layout
Interactive UI states

🧩 Checkbox Behavior
Default checkbox is hidden using appearance: none
When checked:
Background color changes
Border color changes
Checkmark (✓) appears in the center
Label can change style based on state

▶️ How to Run
Open the project folder
Open index.html in your browser
Click on feature cards to toggle selection

👨‍💻 Purpose
This project was created to practice building custom interactive form components and mastering CSS pseudo-classes for UI behavior.
