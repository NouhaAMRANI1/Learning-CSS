📁 Newspaper Grid Layout Project
📌 Description

This project is a newspaper-style webpage built using CSS Grid. It organizes articles, a cover image, and headlines into a structured multi-column layout similar to a real news website.

📰 Features
Grid-based newspaper layout
Main title header spanning full width
Feature article with larger space
Cover image positioned alongside articles
Secondary article section
Three small news articles
Responsive grid structure using named areas

🛠️ Technologies Used
HTML5
CSS3

🎯 Key Concepts Practiced
CSS Grid layout (display: grid)
grid-template-columns
grid-template-rows
grid-template-areas
Grid area assignment
Layout structuring with semantic HTML
Image scaling (max-width: 100%)

🧩 Layout Structure
Title row → full-width header
Main content row → feature article + cover image
Secondary row → secondary article + image
Bottom row → three small news articles

🎨 Styling Highlights
Clean multi-column newspaper design
Balanced spacing using grid gaps
Image adapts to container width
Structured content hierarchy
Modern layout using CSS Grid areas

▶️ How to Run
Open the project folder
Open index.html in your browser
View the newspaper grid layout

👨‍💻 Purpose

This project was created to practice CSS Grid and learn how to build complex page layouts similar to real-world news websites using structured grid areas.
