📁 Pricing Plans Project

📌 Description
This project is a simple pricing table layout built using HTML and CSS Flexbox. It displays different subscription plans (Basic, Pro, and Premium) using a responsive card-based design.

💰 Features
Three pricing cards (Basic, Pro, Premium)
Flexbox layout for alignment and spacing
Responsive wrapping of cards
Different flex behaviors per plan
Custom ordering of cards
Highlighted Pro plan using flex growth

🛠️ Technologies Used
HTML5
CSS3

🎯 Key Concepts Practiced
CSS Flexbox (display: flex)
Flex wrapping (flex-wrap)
Flex direction (column)
Flex sizing (flex: 0 0 200px)
Flex growth (flex-grow)
Order property (order)
Box model (margin, padding, border)

🧩 Layout Behavior
Cards are arranged horizontally using Flexbox
On smaller screens, cards wrap to the next line
The Pro plan grows larger than other cards
Custom ordering controls visual placement
Each card maintains consistent spacing and styling

▶️ How to Run
Open the project folder
Open index.html in your browser
View the pricing cards layout

👨‍💻 Purpose
This project was created to practice Flexbox layout techniques and understand how flex properties like order and flex-grow affect UI structure and responsiveness.
