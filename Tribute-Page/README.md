📁 Tribute Page Project
📌 Description

This project is a simple tribute page dedicated to Albert Einstein. It was built using HTML and CSS and follows a clean structure with image, caption, biography text, and an external reference link.

🧠 Features
Tribute page layout using semantic structure
Centered responsive image
Image caption section
Short biography text
External link to Wikipedia
Clean and minimal design

🛠️ Technologies Used
HTML5
CSS3

🎯 Key Concepts Practiced
Semantic HTML structure (main, div, img, a)
Image responsiveness (max-width: 100%, height: auto)
Centering elements with margin: 0 auto
External linking with target="_blank"
Basic page layout design
ID-based styling

🧩 Page Structure
Title → Tribute heading
Image section → Einstein photo + caption
Info section → short biography text
Link section → Wikipedia reference

🎨 Styling Highlights
Centered image layout
Responsive image scaling
Clean minimalist structure
Simple focus on readability and content

▶️ How to Run
Open the project folder
Open index.html in your browser
View the tribute page

👨‍💻 Purpose

This project was created to practice building a structured informational webpage and improve layout control and image responsiveness using HTML and CSS.
