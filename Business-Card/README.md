📁 Business Card Project
📌 Description

This project is a simple digital business card built using HTML and CSS. It displays personal information, contact details, and social media links in a clean centered layout.

✨ Features
Profile image display
Name, job title, and company section
Contact information (email & phone)
Portfolio link
Social media links (Twitter, LinkedIn, GitHub)
Centered card layout
Simple and clean design

🛠️ Technologies Used
HTML5
CSS3

🎯 Key Concepts Practiced
Card layout design
Centering elements using margin auto
Image responsiveness (max-width: 100%)
Typography styling
Link styling (text-decoration: none)
Spacing using margin and padding
Semantic structure of profile data

🧩 Layout Structure
Profile image at the top
Personal details (name, role, company)
Divider lines (<hr>) separating sections
Contact info section
Social media links section

🎨 Styling Highlights
Soft rosybrown background
Centered business card container
Simple minimalist typography
Clean spacing between elements
Image scales properly inside the card

▶️ How to Run
Open the project folder
Open index.html in your browser
View the business card layout

👨‍💻 Purpose

This project was created to practice building profile cards and improve understanding of layout structure, spacing, and simple UI design using HTML and CSS.
