📁 Camper Cafe Menu
📌 Description

This project is a styled café menu webpage built using HTML and CSS. It was created as part of FreeCodeCamp practice to learn layout design, typography, and structuring content using semantic HTML elements.

✨ Features
Café menu layout with sections for Coffee and Desserts
Itemized pricing system
Centered menu card design
Background image for realistic café feel
Styled images for menu sections
Footer with address and external link
Hover effects on links

🛠️ Technologies Used
HTML5
CSS3

🎯 Key Concepts Practiced
Semantic HTML (main, section, article, footer, address)
Typography and font styling
CSS background images
Inline-block layout for menu items
Centering elements with margins
CSS pseudo-classes (:hover, :visited, :active)
Box model (padding, margin, width)
Responsive container sizing

🧩 Layout Structure
Header with café name and establishment date
Coffee section with drink items and prices
Desserts section with items and prices
Footer with website link and address

🎨 Styling Highlights
Coffee-themed background image
Burlywood menu card container
Impact font for headings
Clean alignment of item names and prices
Interactive link styling (hover/active states)

▶️ How to Run
Open the project folder
Open index.html in your browser
View the café menu design

👨‍💻 Purpose

This project was created to practice real-world page layout using semantic HTML and CSS styling techniques, especially focusing on menu-style UI design.
