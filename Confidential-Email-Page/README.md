📁 Confidential Email Project

📌 Description
This project is a styled “confidential email” layout built using HTML and CSS. It was created as part of FreeCodeCamp exercises to practice CSS transforms, layout styling, and text effects like blur.

✨ Features
Email container layout using <main> element
“CONFIDENTIAL” and “TOP SECRET” stamps
Rotated labels using CSS transforms
Blurred sensitive text using filter effects
Multiple paragraphs with hidden information
Styled document-like appearance

🛠️ Technologies Used
HTML5
CSS3

🎯 Key Concepts Practiced
CSS transform: rotate()
CSS filter: blur()
Inline-block elements
Box model (padding, margin, border)
Positioning and layout structure
Styling spans inside paragraphs
ID and class-based styling

🧾 Special Effects Used
Confidential stamp rotation to simulate stamped document
Top secret label rotation for visual contrast
Blur effect applied to sensitive text using .blurred class
Clean document-style spacing for realism

▶️ How to Run
Open the project folder
Open index.html in your browser
View the styled confidential email layout

👨‍💻 Purpose
This project was created to practice advanced CSS styling techniques and create realistic document-style UI effects using transforms and filters.
