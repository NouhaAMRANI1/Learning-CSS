📁 Contact Form Project

📌 Description
This project is a simple and responsive contact form built using HTML and CSS. It was created as part of FreeCodeCamp and front-end practice exercises to improve form design and validation skills.

✨ Features
Full name input field
Email input field
Message textarea
Submit button
Proper label associations
Required form validation
Focus effects on inputs
Hover effect on button
Clean and centered layout

🛠️ Technologies Used
HTML5
CSS3

🎯 Key Concepts Practiced
Form structure in HTML
Input validation (required, email, text)
Label linking using for and id
CSS styling for inputs and textarea
Pseudo-classes (:focus, :hover)
Box model (padding, margin, width)
Basic responsive layout

▶️ How to Run
Open the project folder
Open index.html in your browser
Test the form by filling inputs and submitting

👨‍💻 Purpose
This project was built to practice creating accessible and well-structured forms using HTML and CSS.
