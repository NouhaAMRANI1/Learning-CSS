📁 Newspaper Layout Project
📌 Description

This project is a newspaper-style webpage built using HTML and CSS. It was created as part of FreeCodeCamp exercises to practice typography, font sizing, and text styling techniques used in editorial design.

📰 Features
Newspaper-style layout
Header with publication name and date
Headline, sub-headline, and author section
Multiple article paragraphs
Styled typography hierarchy
First-letter decorative styling

🛠️ Technologies Used
HTML5
CSS3

🎯 Key Concepts Practiced
Relative font sizing (rem, em)
Typography hierarchy
Text transformations (uppercase)
Font styling (bold, italic)
Line height and indentation
Pseudo-element ::first-letter
Font family usage (serif vs sans-serif)
Layout structuring with divs

🧩 Typography System
Newspaper name → large, uppercase, serif font
Headline → bold and large (em scaling)
Sub-headline → lighter italic style
Author → uppercase bold text
Body text → readable spacing with indentation

🎨 Styling Highlights
Classic newspaper look
Clear hierarchy between headings and body text
First letter of each paragraph enlarged and bold
Clean spacing using margins and line-height
Mixed serif and sans-serif fonts for contrast

▶️ How to Run
Open the project folder
Open index.html in your browser
View the newspaper-style article

👨‍💻 Purpose

This project was created to practice typography control in CSS and understand how to build structured, readable article layouts similar to real newspapers.
