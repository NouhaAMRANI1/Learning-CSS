📁 House Layout Project
📌 Description

This project is a simple house illustration built using HTML and CSS. It uses positioned <div> elements to create a basic 2D house structure, practicing absolute positioning and layout control.

🏠 Features
House container with fixed dimensions
Roof, chimney, windows, and door elements
Absolute positioning for precise layout control
Layering using position: relative and absolute
Simple color-based illustration

🛠️ Technologies Used
HTML5
CSS3

🎯 Key Concepts Practiced
CSS positioning (relative & absolute)
Z-index layering
Box model (width, height, border)
Layout composition using div elements
Element alignment using top/left/right/bottom
Visual structuring without images

🧩 Structure Overview
House container (#house) → main frame
Roof (#roof) → top section
Chimney (#chimney) → positioned above roof
Windows (#window-1, #window-2) → symmetrical placement
Door (#door) → centered bottom element

🎨 Styling Highlights
Warm house background color (#f5deb3)
Red roof for contrast
Blue windows for realism
Brown door and chimney
Clean bordered structure for clarity

▶️ How to Run
Open the project folder
Open index.html in your browser
View the house illustration

👨‍💻 Purpose

This project was created to practice CSS positioning techniques and learn how to build simple illustrations using only HTML and CSS.
