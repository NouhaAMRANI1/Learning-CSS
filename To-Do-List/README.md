📁 Styled To-Do List Project
📌 Description

This project is a styled to-do list built using HTML and CSS. It includes checkboxes for tasks and expandable sub-items with useful external links for each task. It was created to practice list structure, form inputs, and link pseudo-classes.

✅ Features
Interactive to-do list with checkboxes
Each task has a label linked to its checkbox
Sub-item links for extra resources
External links open in new tabs
Styled link states (hover, active, visited, focus)
Clean nested list structure

🛠️ Technologies Used
HTML5
CSS3

🎯 Key Concepts Practiced
HTML lists (ul, li)
Checkbox inputs with labels
Nested lists (sub-items)
Anchor links with target="_blank"
CSS pseudo-classes:
:link
:hover
:active
:visited
:focus
Link styling and accessibility
Text decoration control

🧩 Structure Overview
Main list → tasks
Each task → checkbox + label
Sub-list → resource link
External websites linked for each task

🎨 Styling Highlights
Clean default link color system
Hover effect for better UX
Focus outline for accessibility
Removed underline from sub-item links
Color changes based on interaction state

▶️ How to Run
Open the project folder
Open index.html in your browser
Click tasks and explore links

👨‍💻 Purpose

This project was created to practice interactive lists, form elements, and CSS link pseudo-classes while building a practical to-do style UI.
